
# Contributing to FeatherUI

Thank you for your interest in contributing to FeatherUI!

## Before you contribute

Please open an issue or start a discussion before undertaking a substantial
change. This helps avoid duplicated work and gives us a chance to agree on
the proposed approach.

Keep pull requests focused, explain the motivation for the change, and include
tests or examples where appropriate. Please follow the existing code style and
update documentation when needed.


## Licensing and contributor declarations

FeatherUI is offered under a dual-licensing model:

- **GPL-2.0-or-later**, as described in [`LICENSE.gpl.md`](LICENSE.gpl.md); or
- **Commercial licensing terms**, described in [`LICENSE.commercial.md`](LICENSE.commercial.md).

The commercial license is currently a placeholder and is not yet finalized. The
licensing arrangement may be updated as the project approaches production.

By submitting a pull request containing your own contributions, you must
confirm both declarations in the pull request template:

1. **Rights to contribute:**
   You are the author of the contributed code, or otherwise have all rights and
   permissions necessary to contribute it under the stated terms.
2. **Dual licensing:**
   You agree to the GPL-2.0-or-later licensing of your contribution and grant
   the project copyright holder the rights described in
   [`LICENSE.commercial.md`](LICENSE.commercial.md), including the intended
   royalty-free commercial use and licensing rights.

Both checkboxes must be checked before a pull request can be merged. An
automated check may verify that the boxes are checked, but it cannot verify
that the statements are true or replace your responsibility to read and
understand them.

Do not submit code unless you have the right to do so. If your contribution
includes code written by someone else, code copied from another project, or
code created for an employer or client, disclose that clearly in the pull
request and ensure that the necessary permissions are in place. Preserve
third-party copyright and license notices. Do not assume that having access
to code means you have the right to contribute it.

If you cannot agree to either declaration, please do not submit the
contribution under this process. Contact the maintainer to discuss alternatives
before submitting code.


## Third-party dependencies and example code

Third-party code in `external/` is subject to its own license terms. The
project intends to use MIT-licensed third-party code there; retain the
applicable copyright and license notices.

Code in `demo/` and `examples/` is intended to demonstrate how to use FeatherUI
and is meant to be reusable without restriction, including for commercial
purposes. Please do not copy third-party code into these directories without
checking its license and preserving any required notices.


## Signed commits

Signed commits are welcome, but they are not currently required. Commit
signatures can help verify the provenance of a commit; they do not establish
copyright ownership or replace the contributor declarations above.


## Pull request checklist

Before requesting review, please make sure that:

- [ ] Both contributor declarations in the PR template are checked.
- [ ] The change builds and relevant tests pass.
- [ ] Documentation and examples are updated where appropriate.
- [ ] Any third-party code and required notices are identified.
- [ ] The pull request explains what changed and why.

Thank you for helping improve FeatherUI!
